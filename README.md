# Floating Protractor

Windows always-on-top protractor for classroom measurement.

**Features:** 180° and 360° mode, central pivot, independently draggable orange measuring arm, blue rotation handle, live degrees, hide/reveal, angle entry.

Go to **Actions → Build Windows Installer** to get a Windows .exe installer under run Artifacts. Windows SmartScreen may warn because the application is not code-signed.

This is an initial build awaiting Windows classroom testing. The transparent window can intercept mouse clicks in blank regions, and moving between monitors may need further work.
